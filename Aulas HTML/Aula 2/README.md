# Página de Perfil Pessoal — João Victor Paschoal

Mini página web desenvolvida com o objetivo de praticar e consolidar conhecimentos em **HTML** e **CSS**, servindo como um cartão de visitas / perfil pessoal online.

## 📋 Sobre o projeto

Este projeto é uma página estática simples que apresenta informações pessoais e profissionais, incluindo:

- Foto de perfil e dados de contato
- Seção "Sobre mim"
- Objetivos profissionais
- Experiência
- Formação acadêmica

O foco principal foi praticar estruturação semântica de HTML e estilização com CSS (Flexbox, bordas arredondadas, sombras, cores e tipografia).

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação do conteúdo
- **CSS3** — estilização e layout (Flexbox)

## 🎨 Destaques do CSS

- Layout do cabeçalho com **Flexbox** (`display: flex`), alinhando foto e informações lado a lado
- Foto de perfil circular com `border-radius: 50%` e sombra suave
- Seções de conteúdo com fundo destacado, texto justificado e bom espaçamento de linha
- Container central responsivo com largura máxima definida
