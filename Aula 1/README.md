# Aula 1 - HTML Básico

Esta pasta contém exercícios introdutórios de HTML, cobrindo as principais tags estruturais, de texto, mídia, listas, tabelas e formulários.

## 📁 Estrutura

```
Aula 1/
├── index.html              # Página principal com tags básicas de HTML
├── page1.html               # Segunda página com formulário
├── html_basic_tags....      # Imagem ilustrativa usada em index.html
├── 54b515911840d...          # Imagem ilustrativa usada em index.html
└── README.md
```

## 📄 index.html

Página de apresentação das principais tags de HTML, com exemplos práticos de cada uma:

- **Texto e formatação:** `<h1>`, `<h2>`, `<p>`, `<strong>`, `<b>`, `<em>`, `<br>`
- **Imagens:** `<img>` (locais e via URL externa, incluindo GIFs)
- **Links:** `<a>` (link externo e link para imagem clicável)
- **Listas:** `<ul>` (não ordenada) e `<ol>` (ordenada)
- **Tabela:** `<table>` com `<th>`, `<tr>` e `<td>`, comparando tecnologias de front-end, back-end e banco de dados
- Link final de navegação para `page1.html`

## 📄 page1.html

Segunda página, focada em elementos de **formulário**:

- **Campo de texto:** `<input type="text">` com `<label>`
- **Botões de opção (radio):** seleção de gênero
- **Seleção (select/option):** marcas de carro
- **Lista de sugestões (datalist):** sabores de suco, usando `<input list>` combinado com `<datalist>`
- **Agrupamento de campos:** `<fieldset>` e `<legend>`
- **Botões de ação:** `<input type="reset">` e `<input type="submit">`
- Link de retorno para `index.html`

## 🎯 Objetivo da atividade

Praticar a escrita de HTML semântico básico, entendendo o papel de cada tag na estruturação de conteúdo, mídia, navegação, listas, tabelas e formulários.

## 🛠️ Tecnologias

- HTML5

## ▶️ Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador. A navegação entre as páginas é feita pelos links internos.
