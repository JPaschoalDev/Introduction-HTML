# Aula 3 - Site Institucional: PowerFit Academia

Site institucional fictício de uma academia, desenvolvido com **HTML e CSS**.

## 📁 Estrutura

```
Aula 3/
├── index.html          # Página inicial
├── README.md
├── Pages/
│   ├── sobre.html        # Página Sobre
│   ├── servicos.html     # Página de Serviços
│   └── contato.html      # Página de Contato
├── Styles/
│   └── style.css         # Estilização do site
└── images/
    ├── hero.jpg
    ├── sobre.jpg
    ├── servico-musculacao.jpg
    ├── servico-crossfit.jpg
    ├── servico-zumba.jpg
    └── servico-personal.jpg
```


## Páginas

- **index.html**: apresentação da academia e imagem de destaque.
- **sobre.html**: texto sobre a academia e imagem da estrutura.
- **servicos.html**: 4 serviços oferecidos (Musculação, Crossfit, Zumba, Personal Trainer), cada um com nome, descrição e imagem.
- **contato.html**: endereço, telefone, horário de funcionamento e links para redes sociais.

Todas as páginas possuem um menu de navegação no topo que leva às demais.

## Tecnologias

- HTML5
- CSS3

## Como visualizar

Abra o arquivo `index.html` em qualquer navegador. A navegação entre as páginas é feita pelo menu no topo.
