# Repositório de Estudos — Desenvolvimento Web

Repositório criado para registrar minha evolução no aprendizado de **desenvolvimento web**, organizado por aulas/projetos. Cada pasta representa uma aula ou etapa de estudo, com seu próprio código e README explicando o que foi praticado.

## 🎯 Objetivo

Documentar minha jornada de aprendizado em HTML, CSS, JavaScript e outras tecnologias web, praticando conceitos novos a cada aula e mantendo um histórico evolutivo do meu progresso.

1. Clone o repositório:
